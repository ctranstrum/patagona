# Patagona Cases

For keyboard case files, see the keyboard-specific subdirectories:

- [Patagona chaski cases](chaski#readme)
- [Patagona gigas cases](gigas#readme)

## Five-way switch caps

This directory also contains two printable caps for the five-way switch used on the Patagona gigas:

| file                        | description                              |
| --------------------------- | ---------------------------------------- |
| [joystick.stl](joystick.stl) | joystick-style cap (recommended)        |
| [dpad.stl](dpad.stl)        | dpad-style cap (experimental)            |

Each cap has a corresponding `.cjs` source file that can be opened and edited at
[jscad.app](https://jscad.app) if you'd like to modify the design.
